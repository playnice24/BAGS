# BoundedDualGS-AGPF

Research code release for an ongoing robotics project.

## Project status

This repository is a preliminary public placeholder for an ongoing research project. The full implementation and detailed experimental materials are intentionally not included at this stage. A complete release may be prepared after the associated manuscript and code have been finalized.

## Scope

The project concerns:

1. resource-aware Gaussian scene representations;
2. RGB-D tracking and mapping;
3. Gaussian-based local navigation.

## Repository layout

Only non-sensitive project metadata and selected configuration examples are retained in this preliminary repository.

Datasets, pretrained weights, and generated results are maintained separately from this public source release.

Detailed environment, protocol, and reproducibility instructions will be added with the complete release.
